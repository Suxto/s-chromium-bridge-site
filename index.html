S Chromium Bridge

A local developer bridge for testing and debugging websites in your existing browser.

What it does

S Chromium Bridge connects Chrome or Edge to a companion installed on the same computer. After the user explicitly enables access, approved local developer tools can inspect and interact with selected HTTP(S) pages, collect bounded diagnostics, and apply user-created request-modifier profiles.

  • Inspect page structure and use semantic browser actions.
  • Capture screenshots, PDFs, console output, and bounded network diagnostics.
  • Apply explicit, scoped request and response modifications for local testing.
  • Stop all active sessions immediately from the extension popup.

Safety defaults

  • The Native Host bridge and request modification are off by default.
  • Raw Chrome DevTools Protocol access is separately disabled by default.
  • The companion listens only on localhost and requires a per-install bearer token.
  • The developer does not receive browsing data, analytics, or profile contents.
