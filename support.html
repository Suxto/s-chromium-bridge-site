Support and installation

Requirements

  • Google Chrome or Microsoft Edge 120 or newer.
  • macOS or Linux.
  • Node.js 22.19 or newer for the local companion.

Install the local companion

The extension's browser-control features require the separately installed companion. Download the reviewer-accessible companion package, then run: 

npm install --global ./sunxiaotong.666-s-chromium-bridge-0.1.1.tgz
s-chromium-bridge install-host --browser chrome --json
s-chromium-bridge doctor --json

Verify the package with the published SHA-256 checksum before installation.

Open the extension popup, review the browser-data disclosure, and enable Native Host bridge. Request modification is separately controlled by the switch beside Profiles.

Troubleshooting

  1. Confirm that the extension and companion versions match.
  2. Run s-chromium-bridge doctor --json.
  3. Reload the extension after upgrading the companion.
  4. Keep Full CDP access off unless the requested task specifically needs it.
  5. Use Stop all to terminate active sessions and debugger attachments.
