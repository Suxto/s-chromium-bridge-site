Privacy Policy

Effective date: September 19, 2026

Summary

S Chromium Bridge is a local web-development tool. The extension does not send browsing data, analytics, or request-modifier profiles to the developer. When the user enables the Native Host bridge, the extension communicates with a companion installed on the same device. Software that the user authorizes to call that companion may receive data needed to perform the user's requested browser task.

Data the extension handles

Depending on the feature the user invokes, the extension may process:

  • browser tab URLs, titles, group membership, and navigation state;
  • website content and accessibility information;
  • screenshots, generated PDFs, console output, and bounded network diagnostics;
  • files the user explicitly uploads or downloads through the bridge;
  • request-modifier profile values, including headers, cookies, redirects, and filters;
  • authentication or other sensitive page data only when exposed by a user-enabled browser operation, such as Full CDP access.

This handling occurs even when data remains on the user's device. The extension does not include advertising, analytics, telemetry, or developer-operated collection endpoints.

How data is used

Data is used only to provide the extension's single purpose: local browser testing and debugging requested by the user. This includes page inspection and interaction, diagnostics, file transfer, and scoped request or response modification.

Data is not sold, used for advertising, credit decisions, or transferred for unrelated purposes. The developer does not permit humans to read user data except when the user deliberately includes specific information in a support request or when required by law.

Local companion and data sharing

The Native Messaging companion runs on the same computer. Its HTTP interface listens only on 127.0.0.1 and requires a random per-install bearer token. Browser data is sent only to this local companion. Other local software can receive data only when it has access to that token and requests an enabled feature. The privacy practices of software using the companion govern any subsequent transmission it performs.

Storage and retention

  • Settings and request-modifier profiles remain in Chrome local extension storage.
  • Temporary browser sessions and approvals expire or are removed when stopped.
  • Transfer data is bounded, temporary, and removed after use or expiration.
  • The local companion keeps configuration and discovery files on the user's device.

Users can delete profiles in the popup, use Stop all to end active work, disable the extension, clear extension storage, or uninstall the extension and companion.

User controls

  • Native Host access and request modification are disabled by default.
  • Chrome asks the user before granting HTTP(S) page access.
  • Full CDP access is separately disabled by default and marked dangerous.
  • Users can stop sessions and debugger attachments from the popup at any time.

Security

The extension uses Manifest V3, a self-only content security policy, bounded messages and results, scoped browser-session identities, output redaction, and exact Native Messaging extension origins. No remotely hosted JavaScript is loaded into the extension.

Children

The extension is a developer tool and is not directed to children under 13.
